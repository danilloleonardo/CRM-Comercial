Armazenamento de dados

Hoje os dados ficam salvos no navegador (localStorage), então funcionam offline e sem custo, mas não sincronizam entre computador e celular. O código já está estruturado para trocar isso por Firebase sem reescrever as telas — veja os comentários FIREBASE: no arquivo.

Login (Firebase Authentication)

Ainda não configurado. Quando você criar o projeto no Firebase, cole a config no bloco indicado e troque as funções de DataStore pelas chamadas ao Firestore — os nomes de função permanecem os mesmos.

// FIREBASE: inicializar app + auth aqui (ver comentário no <script>)

Interpretação de atividades por IA (Google Gemini)

O registro rápido já separa "texto digitado" de "interpretação". Hoje a interpretação é feita por um parser simples em JavaScript; o ponto exato para plugar a chamada ao Gemini está comentado como GEMINI: na função parseActivityText.

// GEMINI: enviar activityText para a API e receber {cliente, tarefa, data, contexto}
